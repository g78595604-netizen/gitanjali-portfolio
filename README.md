# Gitanjali — Developer Portfolio

A responsive React + Vite portfolio with a warm lavender, blush and cream visual style, animated hero, coding-girl artwork, project showcase, skills, education and contact sections.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Open Terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Before publishing — personalize these details

Search in `src/App.jsx` and replace:
- `your.email@example.com` with your professional email.
- LinkedIn placeholder with your actual profile URL.
- Add the correct GitHub repository URLs for RoadSOS, Weather App and SakhiSetu.
- Verify each project's description, technologies, status and your individual contribution.
- Add your actual resume PDF as `public/resume.pdf` so the Resume button works.
- Add verified hackathon names, dates, roles and results in the Journey section.

The six projects are intentionally labelled with their current known or unconfirmed status. Update them only after verifying the implementation.

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

Push the project to GitHub and import the repository into Vercel. Use the default Vite build command `npm run build` and output directory `dist`.
